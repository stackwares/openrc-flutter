# Security policy

OpenRC handles RevenueCat sign-in sessions, so we take reports seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository
([direct link](https://github.com/stackwares/openrc/security/advisories/new)).

Include what you found, how to reproduce it, and what an attacker could do.
We'll acknowledge it within three working days and keep you posted until it's
fixed. We're glad to credit you in the advisory unless you'd rather stay
anonymous.

## Scope

- The OpenRC apps (iOS, iPadOS, Android, macOS, web) in this repository.
- The web relay in [`relay/`](relay/) and its official deployment.

Issues in RevenueCat's own service belong with
[RevenueCat](https://www.revenuecat.com/security/).

## Supported versions

Fixes go into the latest release on each platform.
